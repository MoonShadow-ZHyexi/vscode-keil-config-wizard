# Keil 文本配置向导

打开包含可编辑向导配置的文件时，编辑器右上角会出现「切换到 Keil 配置向导」图标。点击图标可将当前文本标签页切换为向导。向导右上角的「切换到文本编辑器」图标可切回源文件。两种视图在同一个编辑器分区和标签位置来回替换。向导内容在切换时淡入或淡出，开启「减少动态效果」时会直接切换。

也可以在编辑器中右键选择「打开 Keil 配置向导」。表单修改会自动保存整个源文件，包括文件中已有的未保存修改。首个顶层分组用作大纲的固定标题，下面的配置区按分组显示为树形目录。点击分组可跳转，分组箭头和顶部图标可展开或折叠子分组。聚焦分组后，可用方向键浏览树形目录，用 Enter 跳转。向左拖窄分隔条可收起大纲，向右拖动可恢复。也可以在配置页面右键选择「打开大纲」或「关闭大纲」。也可在分隔条上使用左右方向键。可以使用 VS Code 的撤销功能。

支持分组、数字、下拉选项、数字范围和步长、位域、复选框、字符串及帮助文本。代码块开关与数值换算标注目前仅提示，不能编辑。

对于缺少 Keil 起始标记的旧文件，向导也能识别紧跟在配置注释后的简单 `#define` 常量，包括带一层括号的字面量。

整数输入框按源文件写法显示，例如 `0b0011`、`077`、`42` 和 `0X00AFU`。支持大小写前缀、数字分隔符、C/C++ 整数类型后缀，以及汇编写法如 `0011B`、`0011Y`、`2_0011`、`077Q`、`0AFH` 和 `&AF`。范围、位域和下拉匹配按数值处理，修改后按源文件的进制和写法保存。

新打开的文件默认使用文本编辑器。首次进入配置向导时，大纲默认打开。再次进入向导时，会恢复大纲开关、宽度、折叠状态、选中分组和滚动位置。重新启动 VS Code 并恢复工作区时，退出前仍打开的配置向导标签页也会在原编辑器分区恢复。

向导标签页打开期间，插件会在工作区设置的 `workbench.editorAssociations` 中为该文件添加临时路径规则，供普通资源管理器直接复用已有标签页。关闭向导标签页或切回文本时，插件会清理自己添加的规则。

可以打开 [example.h](example.h) 体验。编写自己的配置文件时，可参考[配置向导编写规则](CONFIGURATION_WIZARD_RULES.md)。

# Keil 文本配置向导

在 VS Code 中打开项目文件夹或工作区。在资源管理器中右键文件，或在文件编辑器中右键，选择「添加到 Keil 配置向导」。点击资源管理器「Keil 配置向导」视图中的条目，可在当前编辑器分区打开配置表单。右键条目并选择「打开源文件」，可在文本编辑器中查看对应文件。

也可以从资源管理器把文件拖到「Keil 配置向导」列表。拖到已打开的向导页面时，按住 Shift 可将文件交给向导处理。两种方式都会把文件加入当前工作区的列表。

视图可通过资源管理器的视图菜单显示或隐藏。右键列表中的条目，或点击条目旁的移除按钮，可将文件从列表移除并关闭对应的配置向导标签页。列表保存在项目目录的 .vscode/keil-config-wizard.json 中，项目内文件使用相对路径。多根工作区分别保存在各项目目录中，工作区外的文件保存在第一个项目的列表中。旧版列表会在打开视图时迁移。

也可以在编辑器中右键选择「打开 Keil 配置向导」。表单修改会自动保存整个源文件，包括文件中已有的未保存修改。首个顶层分组用作大纲的固定标题，下面的配置区按分组显示为树形目录。点击分组可跳转，分组箭头和顶部图标可展开或折叠子分组。聚焦分组后，可用方向键浏览树形目录，用 Enter 跳转。向左拖窄分隔条可收起大纲，向右拖动可恢复。也可以在配置页面右键选择「打开大纲」或「关闭大纲」。也可在分隔条上使用左右方向键。可以使用 VS Code 的撤销功能。

支持分组、数字、下拉选项、数字范围和步长、位域、复选框、字符串及帮助文本。代码块开关与数值换算标注目前仅提示，不能编辑。

首次打开文件的配置向导时，大纲默认收起。再次打开时，会按工作区和文件恢复大纲开关、宽度、折叠状态、选中分组和滚动位置。重新启动 VS Code 并恢复工作区时，退出前仍打开的配置向导标签页也会在原编辑器分区恢复。

可以将 example.h 添加到列表体验。

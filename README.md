# Keil 文本配置向导

打开包含可编辑向导配置的文件时，编辑器右上角会出现「切换到 Keil 配置向导」图标。点击图标可将当前文本标签页切换为向导。向导右上角的「切换到文本编辑器」图标可切回源文件。两种视图在同一个编辑器分区和标签位置来回替换。向导内容在切换时淡入或淡出，开启「减少动态效果」时会直接切换。

点击右上角的「切换源文本预览」，可在同一 VS Code 窗口的相邻编辑器组中，并排使用左侧原生文本编辑器和右侧配置向导。两侧编辑的是同一份文件。左侧使用 VS Code 的文本编辑和保存设置，右侧的配置修改会自动保存。拖动 VS Code 分隔线可以调整两栏宽度。再次点击预览图标会回到开启预览前的模式。点击「切换到 Keil 配置向导」或「切换到文本编辑器」会关闭预览并进入所选模式。

也可以在编辑器中右键选择「打开 Keil 配置向导」。配置项按源文件的分组显示为树，可用顶部按钮全部展开或折叠，也可点击分组名称或箭头单独操作。用 `<z>` 创建固定展开的分组，用 `<if>` 等标注控制配置项是否可编辑。表单修改会自动保存整个源文件，包括文件中已有的未保存修改。可以使用 VS Code 的撤销功能。

支持分组、位域、复选框、字符串、整数、符号和定长整数数组。可以按名称绑定变量或宏，用下拉选项选择整数或符号，也可以为配置项提供「恢复默认」按钮。启用分组关闭时，子项会置灰。代码块开关可逐行切换注释，数值换算可用于字节、字长等单位。

对于缺少 Keil 起始标记的旧文件，向导也能识别紧跟在配置注释后的简单 `#define` 常量，包括带一层括号的字面量。

普通整数输入框按源文件写法显示，例如 `0b0011`、`077`、`42` 和 `0X00AFU`。可以用 `<f.d>`、`<f.h>`、`<f.o>`、`<f.b>` 指定界面进制。支持旧式范围 `<0-255>` 和带负数及步长的范围 `<-50..100:10>`。修改后按源文件的进制和写法保存。

首次打开文件时使用文本编辑器。切换编辑模式后，插件会按文件在当前工作区记住上次使用的模式。再次进入向导时，会恢复分组折叠状态和表单滚动位置。关闭预览中的其中一个标签页时，另一个标签页会保留。重新启动 VS Code 并恢复工作区时，退出前仍打开的标签页会随编辑器布局恢复。

工作区内的文件会使用 `workbench.editorAssociations` 中的精确路径规则，让资源管理器直接打开记住的模式或复用已有标签页。切回文本编辑器时，插件会清理自己为该文件添加的规则。

可以打开 [example.h](example.h) 体验。编写自己的配置文件时，可参考[配置向导编写规则](CONFIGURATION_WIZARD_RULES.md)。
